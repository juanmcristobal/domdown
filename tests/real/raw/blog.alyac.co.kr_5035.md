[표 1] ESRC최근 수집한 데이터 참고

택배 스미싱의 주요 내용으로는 배송 실패가 주를 이루고 있으며 악성 앱이 정교해질 뿐 기존에 문자들과 크게 차이가 없습니다.단축 URL을 통한 악성 앱 유포도 동일하기 때문에 스미싱의 예방 방법은 생각보다 간단합니다.문자에 포함된URL링크를 클릭하지 않도록 하고 실수로 다운로드한 악성 앱이라도 설치하지 않으면 됩니다.

**앱 정보 및 실행 화면**

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FbjsxWc%2FbtrVfsm0VWY%2FAAAAAAAAAAAAAAAAAAAAAGcoArxPjAZ7GNXe56vrxjpx0TiG42xzts9ofUtqN6cU%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DlR6ih9M2pWPcNaYt%252FuXOrrqCuHY%253D)[그림 1] 배포 사이트

문자에 포함된 링크를 누르면[그림1]과 같은 사이트로 이동합니다.겉보기에는 정상적인 사이트 같지만, URL이 실제 사이트와 다릅니다.또한,조회를 위해 핸드폰 번호를 입력할 텐데 무분별한 다운로드를 방지하기 위해 미리 등록된 번호를 체크합니다.배포 사이트에 등록된 번호가 아니라면 입력 번호 오류를 표시하고3번 시도 후에는 이상하게도 CJ대한통운 사이트로 이동시킵니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2Fbm2Eh4%2FbtrVak4zRww%2FAAAAAAAAAAAAAAAAAAAAABY11Sns3-VvhG1-8tLnKVzOh11k5Zko03PwCBj_KSd5%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DMp6HPEVnVlgHksP5aiIWDP4Lv3c%253D)[그림 2] 다운로드 사이트

공격자가 미리 정해놓은 번호를 입력했을 경우 [그림 2]와 같은 페이지로 이동하며 앱 다운로드가 가능합니다.설치 후 조치 방법에 대해서도 자세하게 설명하고 있으므로 정상적인 페이지로 오인할 수 있습니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FbuBgPI%2FbtrU8GmyWoe%2FAAAAAAAAAAAAAAAAAAAAADoRii053J6u12A8wtPwv25vsBJkGJAXA1Okdw1YVKig%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3D411NwaiR2x8CZlJoZoC0SwbshFY%253D)[그림 3] 앱 정보

다운로드 받은 앱의 경우 사용자를 속이기 위해 아이콘과 이름을 로젠택배로 사칭하고 있습니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FbrJ3YH%2FbtrU7IrkYdn%2FAAAAAAAAAAAAAAAAAAAAAHi2ydsTg8IUVIakkZlwWNQSMlZTI0a0RA8dpfnKeY7u%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DbG25t68Sa%252FMF4Wrvtah%252BgSc2xLM%253D)[그림 4] 추가 앱 설치

앱을 실행하면 가장 먼저 추가 앱 설치를 유도하고 설치하지 않으면 다음 화면으로 넘어가지 않습니다.실질적인 악성 행위를 담당하기 때문에 정상적인 보안 앱의 이미지를 사칭하여 설치를 유도합니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FbTelRa%2FbtrU8E98rvy%2FAAAAAAAAAAAAAAAAAAAAAH07VBguyK74nrh8uMPZbYABS0q3KnmufI2o1dvKrvvr%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3Dvs1eQx1q4cL1rLDfKPyp4FeyaYI%253D)![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FtsmaZ%2FbtrVaSAbJpr%2FAAAAAAAAAAAAAAAAAAAAAH3S7yYWY7MQGFhkVQUvsAsA6jwtJvgkUOla7mHDbYkt%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DC1tv1%252FvtQi46vPFhuQqegy1%252BuaY%253D)![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FbugG1s%2FbtrU9eQ3C6S%2FAAAAAAAAAAAAAAAAAAAAAPYA8m2v4HmqVmOOb205yleiZpBw6di-TXBHaEWcGnEv%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3Dx5whuxX0%252B5occnn8YMU2Z19g7wM%253D) [그림 5] 앱 실행 화면

앱을 실행하면 실제 로젠택배처럼 인트로 화면을 표시하고 이용약관 및 동의를 구하고 있습니다.이는 실제 기능이 없는 보여주기식 화면입니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FcwR1Pb%2FbtrVcMGunDZ%2FAAAAAAAAAAAAAAAAAAAAAF1njj953E8wZub1b-eD6CgUSc4JfMMu-EvykVET6ht_%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DESR7FPHUFs9qrv2fbNdmfACJwmw%253D)![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FbvWzlS%2FbtrVgjpNrv2%2FAAAAAAAAAAAAAAAAAAAAAI5IzPbo2GCuEM0h-zh3_oSHrI6QCuprV-GVRaD266vf%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3D%252BbR8Vlco7oUg5NdGIaPMeObgY%252Fw%253D)![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FcE373C%2FbtrVf89FwRq%2FAAAAAAAAAAAAAAAAAAAAADpMBV5ENIfyb0mJVcNoUedWoBgkjIoHF-wijNiAXkCq%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DAKxZAcpZra3Foi6OsKZHFt9BKqU%253D) [그림 6] 앱 실행 화면

다음으로 전화번호 인증하는 화면이 정상적인 앱과 동일하여 구분이 어렵습니다.휴대전화 인증도 공격자가 미리 등록한 번호가 아니면 다음 화면으로 넘어가지 않습니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2Fdc7tfs%2FbtrVhSrWk6b%2FAAAAAAAAAAAAAAAAAAAAAHZA6pOl1ci_HQSrDeLMfdNnfGwUJYZLpWfhcZU4NStc%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DUkde1czpjK%252BYOC6jJ5u%252B11WJBTo%253D)[그림 7] 앱 실행 화면

모든 인증 과정을 수행하면 네트워크 연결 상태가 좋지 않다는 문구와 함께 이미지를 띄우고 더 이상 동작하지 않습니다.

본 분석 글에서는 보이스 피싱에 사용되는 악성 앱 **“Spyware.Android.Agent”**를 살펴보도록 하겠습니다.

**코드 분석 - 초기 설정**

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FeoYQ2n%2FbtrVeWIDdbN%2FAAAAAAAAAAAAAAAAAAAAAKhDMA8WBU_gFDDrk_6Dnx3RwFRpixxPybZxGPi37mwr%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DY3n%252B%252B%252FDo9kGrpY0vAh6%252F5y7Pgm8%253D)[그림 8] 초기 루틴

앱 실행 시 가장 먼저 3가지의 함수가 실행되는데 initView, initData, initListener순서대로 동작합니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2Ft8CRI%2FbtrU6X9Vs4y%2FAAAAAAAAAAAAAAAAAAAAAIXZH4sl0Tz8S5e4GcTgBWqw7yiSMvIGAtSsFRk6OZcY%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DKoSMUTOFX9RAgzM3mZVDKj0BjJk%253D)[그림 9] initView

미리 만들어둔 피싱 페이지의URL을 불러와 화면에 표시합니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FydbHe%2FbtrU8ECgN2P%2FAAAAAAAAAAAAAAAAAAAAAFVZeiuEmxngdBz5HSP4zN3qKrmJJvvEHjcsXWLRKQYO%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DX0NwauzDKQHfrLCkCZaOBHjUEqk%253D)[그림 10] initData

2번째 함수는 메일을 통해 폰 번호를 전달하려고 작성한 소스로 보이는데 설치 알림만 전송되고 있습니다.

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2Fpyaq7%2FbtrVamg1wVT%2FAAAAAAAAAAAAAAAAAAAAALjq15iMjJ-ivfrMUW9Nfw_wsDrJKiq_tONibPMlPa2a%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3DfeNTQDi%252F%252Faezoh%252FjaZBtRJ3WESg%253D)[그림 11] initListener

버전을 체크한 후에 리소스에 저장된xx.apk추가 앱을 설치하고 실행합니다.

**코드 분석 - 기능 설명**

악성 앱의 주요 행위는 다음과 같습니다.

- 통화
  - 통화 착, 발신 기록
  - 통화 강제 종료
  - 통화 기록 탈취
  - 통화 기록 삭제
- 문자
  - 전송
  - 탈취
- 음성 녹음 및 탈취
- 연락처 탈취
- 갤러리 탈취
- C2 서버 교체
- C2 명령 수행

![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdna%2FqSZME%2FbtrU56Tu8ts%2FAAAAAAAAAAAAAAAAAAAAAEljB-ZtBXt1qCKgs7jxX9eRWReNYachNtmth0V27vWh%2Fimg.jpg%3Fcredential%3DyqXZFxpELC7KVnFOS48ylbz2pIh7yKj8%26expires%3D1780239599%26allow_ip%3D%26allow_referer%3D%26signature%3D1mAQT8C50sm98q2lErDbpCttXY0%253D)[그림 12] 추가 앱 시작

추가로 설치한 악성 앱은 다양한 기능을 수행하기 위해 서비스를 실행하고 기기 관리자를 등록합니다.또한, setComponentEnabledSetting설정을 통해 아이콘을 숨기고 있습니다.
